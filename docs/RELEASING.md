# Releasing Nuvix

See [release signing and update continuity](signing.md) for signing key creation, required GitHub Actions secrets, versionCode rules, release verification and corresponding source publication. See [building](building.md) for local builds.

Nuvix stable releases are never signed with the Android debug key. Unsigned local release builds are for inspection and cannot be installed. Public APKs require the dedicated Nuvix key so future updates preserve application data.
