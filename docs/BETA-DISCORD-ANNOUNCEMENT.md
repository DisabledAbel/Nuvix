Copy-ready preparation message; not posted by this PR. Do not add an APK download claim

**Nuvix v1.0 beta testing is being prepared!**

We’re looking for volunteers with Android TV, Google TV or compatible Fire TV devices,
including lower-memory hardware, to help test installation, live playback, EPG, Multi-View,
background DVR, remote navigation and updates. **Authorized Stalker portal testing is especially welcome.**

Nuvix is a free GPL IPTV player and supplies no channels, subscriptions or media. Bring only
your own authorized IPTV provider account and provider-approved device identity.

**There is no beta APK available yet.** The first planned candidate is `v1.0.0-rc.1`.
Signing/recovery and release approval prerequisites must be completed first. No release date is guaranteed.
Beta builds may contain bugs; use a spare device where possible and expect incomplete device coverage.

Read the [beta testing guide](https://github.com/DisabledAbel/Nuvix/blob/main/docs/BETA-TESTING.md)
and submit session results or reproducible bugs through the
[GitHub issue forms](https://github.com/DisabledAbel/Nuvix/issues/new/choose) once the program opens.
Use Not Tested for features you could not check. New feature requests may wait until after v1.0.

Never post IPTV credentials, private portal/stream URLs, MAC addresses, device identity fields,
tokens or personal information in GitHub or Discord. Sanitize screenshots and logs before sharing.
